# Bài Tập Cấp 1

Website học tập dành cho học sinh tiểu học lớp 1–5.

## Chức năng
- Giao diện responsive cho máy tính, tablet và điện thoại.
- Các mục Toán, Tiếng Việt, Tiếng Anh, Tự nhiên & Xã hội, Đề kiểm tra và Tài liệu.
- Tìm kiếm nhanh theo môn, nội dung và lớp.
- Lọc nhanh theo lớp 1–5.
- Danh sách bài tập mới và chủ đề nổi bật.
- Menu mobile và thông báo tương tác.

## Chạy project
Mở trực tiếp `index.html` bằng trình duyệt hoặc chạy bằng Live Server trong VS Code.

## Cấu trúc
- `index.html`
- `css/style.css`
- `js/app.js`
